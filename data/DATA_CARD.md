# 제공 자료

이 폴더의 문서, 업무 규칙과 별칭은 KANT NEXT DevDesk 과제를 위해 작성한 테스트 데이터입니다. 실제 회사의 운영 규정이나 고객 정보가 아닙니다. 외부 웹 수집은 하지 않습니다.

| 파일 | 내용 |
|---|---|
| `documents.json` | 원문 6개: 현행 문서 5개와 이전 VPN 문서 1개. `document_id`, `title`, `category`, `status`, `source`, `file` |
| `raw/` | TXT 3개와 HTML 3개. 빈 문단, 하단 문구와 중복 문단의 정제가 필요합니다. |
| `aliases.json` | 초록문은 VPN 원격 접속, 임시열쇠는 API 토큰이라는 업무 별칭 |
| `golden.json` | 제공 평가 질문 2개와 참고 답변, 필요한 원문 ID와 확인 문구 |

`access`는 VPN, API 토큰, 출입문 관련 자료이고 `development`는 Python과 배포 관련 자료입니다. `current`는 현행, `retired`는 이전 문서입니다. `overseas` 분류의 문서는 없으며 자료 없음 사례의 검색에 사용합니다.

`source`의 `devdesk://` 값은 이 데이터 안에서 원문을 식별하는 값이며 접속할 웹 주소가 아닙니다. `file`로 실제 파일을 찾습니다. HTML 로더는 제공 파일의 `<p>` 본문만 읽으며 일반 웹사이트를 처리하는 범용 수집기가 아닙니다.

문단 단위 정제를 마치면 원문 6개에서 청크 8개가 나옵니다. 이전 문서도 인덱스에 저장해 두고 검색 단계에서 상태 필터를 적용합니다. 임베딩은 실제 E5 모델로 생성하며 모델을 처음 받을 때 네트워크가 필요합니다.
